# 飞书合作内容数据表

## 定位

合作内容数据表记录已进入合作流程的视频，并按计划从 YouTube 刷新公开指标。刷新程序只处理已有记录，不会因为搜索结果自动创建运营记录。

## 字段合同

字段顺序如下：

1. 多行文本
2. 内容记录ID
3. 合作自动编号
4. 合作记录ID
5. Channel ID
6. KOL Name
7. 样品记录ID
8. 内容状态
9. 视频URL
10. Video ID
11. Video Title
12. Publish Time
13. Views
14. Likes
15. Comments
16. 互动率(%)
17. 归因点击
18. 归因GMV
19. 归因订单量
20. 归因销量
21. 数据更新时间
22. 数据同步状态
23. 同步错误

合作记录ID、Channel ID 和 KOL Name 从合作红人表查找引用；样品记录ID从样品跟踪表查找引用。

## 字段所有权

人工维护：合作自动编号、视频URL、运营状态及四个归因字段。归因点击、归因订单量、归因销量是整数；归因GMV是保留两位小数且不预设币种符号的数字。程序只写视频解析、YouTube 公开指标及同步状态，不写空白主字段、自动编号、查找引用、人工关联键或归因字段。

## 刷新规则

- 支持原始 Video ID、`watch`、`youtu.be`、`shorts`、`live` 和 `embed` URL。
- 校验视频所属频道与合作记录的 Channel ID。
- Base 内同一视频只能由一条有效记录负责刷新。
- 重复视频的主记录只从非终态且合作匹配有效的记录中选择；已取消、已下架或合作匹配失败的历史记录不会阻断有效记录。新鲜记录仍参与稳定选主。
- 成功记录默认 24 小时后到期；`--force` 可跳过新鲜度检查。
- API 或单项指标不可用时保留最后成功快照，并记录可重试状态。
- 写入前再次读取记录，避免覆盖刚发生的人工变更。

## 手动刷新

```bash
# 只生成更新计划，不写飞书
python main.py refresh-cooperation-content --dry-run

# 刷新到期记录
python main.py refresh-cooperation-content
```

## 验收

- dry-run 不写飞书。
- URL 无效、频道不匹配、重复视频和视频不可用可区分。
- 批量更新失败时可逐条隔离问题记录。
